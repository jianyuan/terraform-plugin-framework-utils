# terraform-plugin-framework-utils

[![Go Reference](https://pkg.go.dev/badge/github.com/jianyuan/terraform-plugin-framework-utils.svg)](https://pkg.go.dev/github.com/jianyuan/terraform-plugin-framework-utils)

Essential helper functions, custom types, and opinionated utilities for the [Terraform Plugin Framework](https://github.com/hashicorp/terraform-plugin-framework).

These helpers grew out of building providers such as [terraform-provider-sentry](https://github.com/jianyuan/terraform-provider-sentry). They cover the boilerplate that most providers end up writing themselves.


ExpectLiteralError returns a regular expression that matches text literally, allowing any whitespace between words. Terraform wraps long error messages across lines, so this is useful with resource.TestStep.ExpectError.

<details><summary>Example</summary>

```go
	"fmt"
```

```go
		var diagsInner diag.Diagnostics
		// add in some errors

		return nil, diagsInner

	var diags diag.Diagnostics
	diags.AddWarning("Outer Warning", "Something went wrong")
	_ = fwdiag.Merge(doSomething())(&diags)

	for _, d := range diags {
		fmt.Printf("[%s] %s: %s\n", d.Severity(), d.Summary(), d.Detail())
	}
}
```

<a name="Describe"></a>
## func [Describe](<https://github.com/jianyuan/terraform-plugin-framework-utils/blob/main/fwschema/describe.go#L39>)

```go
func Describe[S any](ctx context.Context, s S, steps ...Step) S
```

Describe runs steps on every attribute and block in s, including nested ones, and returns the updated schema. s is a resource, data source, ephemeral resource or provider schema. The schema's own description is left alone.

The steps run once on MarkdownDescription and, if it is set, once on Description. An empty MarkdownDescription starts from Description, so attributes that only set Description still get a MarkdownDescription.

<details><summary>Example</summary>
<p>



```go
package main

import (
	"context"
	"fmt"

	"github.com/hashicorp/terraform-plugin-framework-validators/stringvalidator"
	"github.com/hashicorp/terraform-plugin-framework/resource/schema"
	"github.com/hashicorp/terraform-plugin-framework/resource/schema/planmodifier"
	"github.com/hashicorp/terraform-plugin-framework/resource/schema/stringplanmodifier"
	"github.com/hashicorp/terraform-plugin-framework/schema/validator"
	"github.com/jianyuan/terraform-plugin-framework-utils/fwschema"
)

func main() {
	ctx := context.Background()
	s := fwschema.Describe(ctx, schema.Schema{
		Attributes: map[string]schema.Attribute{
			"region": schema.StringAttribute{
				MarkdownDescription: "Region to deploy to.",
				Required:            true,
				PlanModifiers:       []planmodifier.String{stringplanmodifier.RequiresReplace()},
				Validators:          []validator.String{stringvalidator.OneOf("us", "eu")},
			},
		},
	}, fwschema.ForceNew(), fwschema.Enum())

	fmt.Println(s.Attributes["region"].GetMarkdownDescription())
}
```

#### Output

```
<span style="color:red">(Force new)</span> Region to deploy to. Valid values: `us`, `eu`.
```

</p>
</details>

# fwsweep

```go
import "github.com/jianyuan/terraform-plugin-framework-utils/fwsweep"
```

Package fwsweep provides helpers for writing acceptance test sweepers for Terraform Plugin Framework resources.

Call Register from an init function or package\-level var in a \_test.go file, and wire up the sweepers in that package's TestMain:

```
func TestMain(m *testing.M) {
	resource.TestMain(m)
}
```

Then run them with "go test ./... \-sweep=all". Use NewResource to delete items through the resource's own Delete method, or implement Sweepable when a direct API call is simpler.

<a name="Register"></a>
## func [Register](<https://github.com/jianyuan/terraform-plugin-framework-utils/blob/main/fwsweep/register.go#L13>)

```go
func Register[P any](name string, providerData func() P, fn SweeperFn[P], opts ...Option)
```

Register adds a test sweeper named name. When the sweeper runs, it calls providerData to obtain the provider data, collects the items with fn and deletes them with Sweep.

<details><summary>Example</summary>
<p>

Register a sweeper in a \_test.go file of the provider package, and call resource.TestMain from TestMain so that "go test \-sweep=all" runs it.

```go
fwsweep.Register("example_project", func() *apiClient {
	// Build the same client the provider's Configure method passes as
	// provider data, usually from environment variables.
	return &apiClient{}
}, func(ctx context.Context, client *apiClient) ([]fwsweep.Sweepable, error) {
	projects, err := client.ListProjects(ctx)
	if err != nil {
		return nil, err
	}

	var sweepables []fwsweep.Sweepable
	for _, p := range projects {
		sweepables = append(sweepables, fwsweep.NewResource(newProjectResource, client, map[string]any{
			"id": p.ID,
		}))
	}
	return sweepables, nil
}, fwsweep.WithDependencies("example_project_member"))
```

<a name="Sweep"></a>
## func [Sweep](<https://github.com/jianyuan/terraform-plugin-framework-utils/blob/main/fwsweep/sweep.go#L68>)

```go
func Sweep(ctx context.Context, sweepables []Sweepable, opts ...Option) error
```

Sweep deletes all sweepables concurrently and returns the joined errors of any that failed. A failure does not stop the remaining deletes.

<details><summary>Example</summary>
<p>



```go
var deleted atomic.Int32
sweepables := []fwsweep.Sweepable{
	sweepableFunc(func(context.Context) error { deleted.Add(1); return nil }),
	sweepableFunc(func(context.Context) error { return fmt.Errorf("project 2: not found") }),
	sweepableFunc(func(context.Context) error { deleted.Add(1); return nil }),
}

err := fwsweep.Sweep(context.Background(), sweepables, fwsweep.WithConcurrency(2))
fmt.Println(deleted.Load(), err)
// Output:
// 2 project 2: not found
```

#### Output

```
2 project 2: not found
```

</details>

NewResource returns a Sweepable that deletes a resource by calling its Delete method directly. The resource is configured with providerData and given a state built from its schema with the root attributes set.
